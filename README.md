# Database-Project
This repo is for the Database Assignment 2. It contains .sql to initialise a database, create tables and  populate it with arbitrary data. These scripts were created over manually typing sql commands as a central point for all team members so that they could locally run the scripts and have the same database to each run the queries ensuring the results were accurate.
The databases have already been created on each person's server so there is no need to run these when marking.

## Queries
All the SQL queries were taken and condensed into one queries.sql file, this is the file that the python script will run to execute and print out all the queries.

## Running the python script
The python script will ask for login details once ran. This was done to avoid putting anyone's log in details in the code. The login details for any of the group members will suffice and the database is CLEARPOINT.
